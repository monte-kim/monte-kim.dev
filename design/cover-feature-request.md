# 디자인 요청: 포스트 커버 이미지 기능

monte-kim.dev 블로그에 **포스트 커버(대표 이미지)** 기능을 추가하려 합니다.
현재 디자인 캔버스(`Blog Portfolio.dc.html`)에는 커버 관련 화면이 없어서 신규 디자인이 필요합니다.

## 배경 & 현재 상태

- 개발은 완료·라이브 상태 (monte-kim.dev). 커버만 미구현
- DB에는 `posts.cover_url` 컬럼이 이미 있음
- 에디터(화면 2g)에 "Add cover" 대시드 칩이 자리만 잡혀 있음 (현재 비활성)
- 이미지 업로드 파이프라인 존재: 클라이언트에서 300KB 이하로 압축 → Supabase Storage
- 글 본문 이미지는 이미 지원됨 — 이 요청은 **글 상단 대표 이미지** 전용

## 지켜야 할 디자인 시스템 (기존 캔버스 기준)

- 토큰: bg `#FBFBFA` · surface `#FFFFFF` · ink `#1A1A18` · muted `#6F6E69` · border `#D9D8D3` · hairline `#ECEBE7` (다크 팔레트는 화면 3d 참조)
- 폰트: Instrument Sans(UI) / JetBrains Mono(메타·태그·mono 요소)
- 라디우스: 카드 10–12px · 버튼 7–9px · 태그 칩 4px
- 아이콘: 16그리드, 1.5px 스트로크, 라운드 캡 인라인 SVG (화면 2h 세트와 통일)
- 산출물은 기존 캔버스와 같은 방식: **인라인 스타일 HTML 섹션**으로 새 화면 id를 추가
  - 제안 id: `2i`(에디터 커버 상태), `2j`(상세 페이지 커버), 목록 반영 시 `2k`, 모바일 `3e`

## 필요한 화면

### 1. 에디터 — 커버 상태 3종 (2g 확장)

- **커버 없음**: 현재 "Add cover" 칩 그대로 (참고용)
- **업로드 중**: 진행 표시 (스피너/스켈레톤 등 — 디자인 재량)
- **커버 있음**: 제목 위/주변에 커버 프리뷰 + hover 시 **Replace / Remove** 액션
- 위치 제안 필요: Notion처럼 제목 위 풀폭? 아니면 칩 영역에 소형 프리뷰?
- 모바일 에디터(3c) 대응 포함

### 2. 포스트 상세 (2f 확장)

- 커버가 제목 영역과 어떻게 배치되는지: 위치(브레드크럼/태그/제목 대비), 폭(본문 폭 720px vs 풀블리드), 비율, 라운딩/테두리 여부
- 모바일(3b) 대응 포함
- 커버 **없는** 글은 현재 2f 그대로 (커버는 선택 사항)

### 3. 목록 노출 여부 — 결정 필요 ★

현재 글 목록(2e)과 홈 Writing 섹션(2a)은 **텍스트 전용 행** 디자인입니다.
커버 썸네일을 목록에도 넣을지가 가장 큰 결정입니다:

- **A안 — 목록은 텍스트 유지**: 커버는 상세 페이지 + OG 이미지에만. 레이아웃 변경 없음, 커버 없는 글과의 일관성 문제도 없음 (개발 관점 추천)
- **B안 — 목록에 썸네일 추가**: 2e/2a 행 레이아웃 재설계 필요. 커버 없는 글의 placeholder 처리 방안도 함께 필요

B안 선택 시 해당 화면 시안도 요청.

## 함께 정해줄 스펙

1. **권장 비율** — OG 이미지 표준(1200×630, 1.91:1)과 맞추는 것을 제안. 상세 페이지에서도 같은 비율로 노출할지, 다른 비율로 크롭할지
2. 업로드 시 **크롭 UI 제공 여부** (없으면 원본 비율 그대로 object-fit: cover)
3. 다크 모드에서의 처리 (테두리/그림자 등)

## 참고 제약

- 무료 티어: Storage 1GB — 커버도 기존 300KB 압축 파이프라인을 그대로 탐 (별도 대용량 불가)
- 커버는 소셜 공유 시 `og:image`로도 사용될 예정
